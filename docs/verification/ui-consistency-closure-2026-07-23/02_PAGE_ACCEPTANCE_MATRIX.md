## 通用断言

- 22 个 capture 全部满足：`document` 无页面级滚动，page rect 在 content rect 内，一级 section 未被裁切，内部滚动可达首尾，底部空白不超过 16 px。
- 所有 canvas 在所属图表卡片内；实时曲线、CAN 分布、一键检测、告警图使用滚动图例、`containLabel`、`hideOverlap` 或低高度媒体策略。
- `IndustrialButton` 和 `IndustrialActionButton` 统一圆角、颜色、hover/focus-visible/disabled/loading；危险操作保持红色语义。
- `PageDataState` 固定尺寸表达 loading/error/stale/permission-denied/empty，背景刷新不插拔状态节点。
- viewer 的 Network 路由为 403；后端仍是权限真源。
