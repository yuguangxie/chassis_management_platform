# Public Release Redactions

The original audit capture files contained station-private RFC1918 network identifiers. Before publishing this repository, those identifiers were replaced with descriptive redaction markers in the public copies.

The redaction changes no test outcome, timestamp, assertion result, or safety conclusion. The original unredacted captures remain only in the local restricted workspace and are not part of this public repository. All checked-in runtime defaults use `127.0.0.1` loopback endpoints.
